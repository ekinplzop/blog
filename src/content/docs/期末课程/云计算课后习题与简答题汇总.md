### Ch4 虚拟化技术

来源：`7虚拟化技术/4-3 课后作业.pdf`，第 1 页。

1. 什么是虚拟化技术？该技术有哪三种类型？
2. 全虚拟化技术和半虚拟化技术的区别是什么？
3. 什么是寄居架构虚拟机监控器？什么是裸金属架构虚拟机监控器？两者的区别是什么？
4. 硬件虚拟化技术有哪些代表？
5. 什么是轻量级虚拟化技术？其代表是什么？

课外思考，来源：`7虚拟化技术/4-3 课后作业.pdf`，第 2 页。

1. 虚拟化技术对提高计算资源的利用率究竟带来了怎样的好处？
2. 轻量级虚拟化技术相对于传统虚拟化技术的优势和不足是什么？
3. 容器的轻量级虚拟化技术还能进一步轻量化吗？有什么样的方式？

动手实践，来源：`7虚拟化技术/4-3 课后作业.pdf`，第 3-4 页。

1. 通过 KVM 官方网站下载并安装使用 KVM，进一步了解 KVM 的原理。
2. 通过 Phoronix 基准测试程序对一个 KVM 系统的性能进行评测和比较。
3. 通过 Docker 官方网站下载并安装使用最新的 Docker，进一步了解 Docker 的原理。
4. 通过基准测试程序对容器和传统虚拟机的性能进行评测和比较。

## 真题关联提示

从往年真题回忆看，下面这些课后题和真题重合度最高：

1. 云计算特点、分类、技术体系结构。
2. ACID、CAP、BASE、最终一致性。
3. 云计算工作负载四种模式。
4. 云栈和云体。
5. 软件定义的数据中心、软件定义一切。
6. 虚拟化定义、全虚拟化、半虚拟化、硬件辅助虚拟化。
7. Type I/Type II Hypervisor。
8. 轻量级虚拟化、Docker 与传统虚拟机对比。
9. 集中式存储与分布式存储、存储类型、SAN/NAS。
10. 覆盖网络、VXLAN、大二层、SDN、控制平面和数据平面、NFV。

HDFS、MapReduce、HBase、ZooKeeper 的过程题和架构题不完全来自这些“课后习题”页，还需要结合 Hadoop/HBase/ZooKeeper 专题课件、学习通作业和往年真题继续复习。

### 复习策略

1. 课后习题优先背：云计算分类与特点、ACID/CAP/BASE、工作负载、云栈云体、虚拟化分类、Hypervisor、轻量级虚拟化、分布式存储类型、SDN/NFV/VXLAN。
2. 课后习题只能当入口：KVM、租户网络、OpenStack、结构化/半结构化/非结构化数据、一致性哈希。
3. 不能只靠课后习题：HDFS、MapReduce、HBase、ZooKeeper。它们要按往年真题模板单独复习。
