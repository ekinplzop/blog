# 数据结构综合应用题解析与答案

说明：顺序表 = 用连续数组保存线性表元素，并用 `length` 记录当前元素个数。下标统一按 C/C++ 语言从 `0` 开始；若教材按 `1` 开始，数组下标整体平移即可。原地算法 = 除少量临时变量外，不使用随输入规模增长的辅助空间。下面代码采用考研 C++ 写法：顺序表需要被修改时用引用传参，数组题用下标或游标处理，不额外写指针。

通用定义：

```cpp
#include <iostream>
#include <climits>
using namespace std;

#define MaxSize 1000

using ElemType = int;

struct SqList {
    ElemType data[MaxSize];
    int length;
};

void Swap(ElemType &a, ElemType &b) {
    ElemType t = a;
    a = b;
    b = t;
}
```

## 01 删除顺序表最小元素

解析：先扫描一遍找到最小元素的位置 `pos`，再用最后一个元素覆盖 `pos`，最后长度减 `1`。

```cpp
bool DelMin(SqList &L, ElemType &value) {
    if (L.length == 0) {
        cout << "顺序表为空\n";
        return false;
    }

    int pos = 0;
    value = L.data[0];
    for (int i = 1; i < L.length; i++) {
        if (L.data[i] < value) {
            value = L.data[i];
            pos = i;
        }
    }

    L.data[pos] = L.data[L.length - 1];
    L.length--;
    return true;
}
```

答案：引用参数 `value` 保存被删最小元素。

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 02 顺序表逆置

解析：首尾元素两两交换，交换到中点停止。

```cpp
void ReverseList(SqList &L) {
    for (int i = 0; i < L.length / 2; i++) {
        Swap(L.data[i], L.data[L.length - 1 - i]);
    }
}
```

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 03 删除所有值为 x 的元素

解析：用 `k` 表示新表下一个可写位置，扫描原表，只把不等于 `x` 的元素写回。

```cpp
void DeleteX(SqList &L, ElemType x) {
    int k = 0;
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] != x) {
            L.data[k++] = L.data[i];
        }
    }
    L.length = k;
}
```

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 04 删除值在 [s, t] 内的元素

解析：保留小于 `s` 或大于 `t` 的元素，其余元素跳过。

```cpp
bool DeleteRange(SqList &L, ElemType s, ElemType t) {
    if (L.length == 0 || s >= t) {
        cout << "参数非法或顺序表为空\n";
        return false;
    }

    int k = 0;
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] < s || L.data[i] > t) {
            L.data[k++] = L.data[i];
        }
    }
    L.length = k;
    return true;
}
```

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 05 删除有序顺序表重复元素

解析：有序表中重复元素必相邻，用 `k` 保存当前最后一个不重复元素位置。

```cpp
void DeleteDuplicate(SqList &L) {
    if (L.length == 0) {
        return;
    }

    int k = 0;
    for (int i = 1; i < L.length; i++) {
        if (L.data[i] != L.data[k]) {
            L.data[++k] = L.data[i];
        }
    }
    L.length = k + 1;
}
```

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 06 合并两个有序顺序表

解析：使用两个下标分别扫描 `A` 和 `B`，每次取较小元素写入 `C`。

```cpp
bool MergeList(const SqList &A, const SqList &B, SqList &C) {
    if (A.length + B.length > MaxSize) {
        return false;
    }

    int i = 0, j = 0, k = 0;
    while (i < A.length && j < B.length) {
        if (A.data[i] <= B.data[j]) {
            C.data[k++] = A.data[i++];
        } else {
            C.data[k++] = B.data[j++];
        }
    }
    while (i < A.length) C.data[k++] = A.data[i++];
    while (j < B.length) C.data[k++] = B.data[j++];

    C.length = k;
    return true;
}
```

复杂度：时间复杂度 `O(m+n)`，空间复杂度 `O(m+n)`，其中结果表 `C` 用于保存答案。

## 07 交换数组中两个线性表的位置

解析：原数组为 `A B`，目标为 `B A`；先整体逆置，再分别逆置前 `n` 个和后 `m` 个元素。

```cpp
void ReverseArray(ElemType A[], int left, int right) {
    while (left < right) {
        Swap(A[left++], A[right--]);
    }
}

void Exchange(ElemType A[], int m, int n) {
    ReverseArray(A, 0, m + n - 1);
    ReverseArray(A, 0, n - 1);
    ReverseArray(A, n, m + n - 1);
}
```

复杂度：时间复杂度 `O(m+n)`，空间复杂度 `O(1)`。

## 08 有序表查找 x，找到则与后继交换，找不到则插入

解析：有序表查找用折半查找；查找失败时，`low` 正好是插入位置。

```cpp
bool SearchSwapOrInsert(SqList &L, ElemType x) {
    int low = 0, high = L.length - 1, mid = 0;

    while (low <= high) {
        mid = (low + high) / 2;
        if (L.data[mid] == x) {
            if (mid < L.length - 1) {
                Swap(L.data[mid], L.data[mid + 1]);
            }
            return true;
        } else if (L.data[mid] < x) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }

    if (L.length >= MaxSize) {
        return false;
    }
    for (int i = L.length - 1; i >= low; i--) {
        L.data[i + 1] = L.data[i];
    }
    L.data[low] = x;
    L.length++;
    return true;
}
```

复杂度：查找时间复杂度 `O(log n)`；插入最坏需要移动元素，总时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 09 输出三个递增序列的公共元素

解析：三个下标分别指向当前元素；三者相等则输出，否则移动当前最小值所在序列的下标。

```cpp
void PrintCommon(const int A[], const int B[], const int C[], int n) {
    int i = 0, j = 0, k = 0;
    while (i < n && j < n && k < n) {
        if (A[i] == B[j] && B[j] == C[k]) {
            cout << A[i] << '\n';
            i++;
            j++;
            k++;
        } else {
            int minv = A[i];
            if (B[j] < minv) minv = B[j];
            if (C[k] < minv) minv = C[k];

            if (A[i] == minv) i++;
            if (B[j] == minv) j++;
            if (C[k] == minv) k++;
        }
    }
}
```

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 10 循环左移 p 个位置

解析：把序列分成 `X[0..p-1]` 和 `X[p..n-1]` 两段，分别逆置后再整体逆置。

```cpp
void LeftShift(ElemType R[], int n, int p) {
    ReverseArray(R, 0, p - 1);
    ReverseArray(R, p, n - 1);
    ReverseArray(R, 0, n - 1);
}
```

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 11 两个等长升序序列的中位数

解析：比较两个序列当前中位数，删除不可能包含总体中位数的一半区间；当剩下两个候选元素时，较小者就是两个序列合并后的第 `n` 小元素。

```cpp
int MedianOfTwoSorted(const int A[], const int B[], int n) {
    int s1 = 0, d1 = n - 1;
    int s2 = 0, d2 = n - 1;

    while (s1 != d1 || s2 != d2) {
        int m1 = (s1 + d1) / 2;
        int m2 = (s2 + d2) / 2;
        int len = d1 - s1 + 1;

        if (A[m1] == B[m2]) {
            return A[m1];
        }

        if (A[m1] < B[m2]) {
            if (len % 2 == 0) {
                s1 = m1 + 1;
                d2 = m2;
            } else {
                s1 = m1;
                d2 = m2;
            }
        } else {
            if (len % 2 == 0) {
                d1 = m1;
                s2 = m2 + 1;
            } else {
                d1 = m1;
                s2 = m2;
            }
        }
    }

    return A[s1] < B[s2] ? A[s1] : B[s2];
}
```

复杂度：时间复杂度 `O(log n)`，空间复杂度 `O(1)`。

## 12 找主元素

解析：主元素出现次数超过一半，和不同元素两两抵消后仍会留下主元素候选；得到候选后必须再扫描验证。

```cpp
int Majority(const int A[], int n) {
    int cand = 0;
    int count = 0;

    for (int i = 0; i < n; i++) {
        if (count == 0) {
            cand = A[i];
            count = 1;
        } else if (A[i] == cand) {
            count++;
        } else {
            count--;
        }
    }

    count = 0;
    for (int i = 0; i < n; i++) {
        if (A[i] == cand) {
            count++;
        }
    }
    return count > n / 2 ? cand : -1;
}
```

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(1)`。

## 13 未出现的最小正整数

解析：长度为 `n` 的数组中，答案只可能在 `1..n+1`；用辅助数组标记 `1..n` 是否出现，再找第一个未标记位置。

```cpp
int FindMissMin(const int A[], int n) {
    bool B[MaxSize + 1] = {false};  // B[i] 表示正整数 i 是否出现

    for (int i = 0; i < n; i++) {
        if (A[i] >= 1 && A[i] <= n) {
            B[A[i]] = true;
        }
    }

    for (int i = 1; i <= n; i++) {
        if (!B[i]) {
            return i;
        }
    }
    return n + 1;
}
```

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(n)`。

## 14 三个升序集合的最小距离

解析：对任意三元组，`D = |a-b| + |b-c| + |c-a| = 2 * (最大值 - 最小值)`；要缩小距离，只能移动当前最小值所在数组的下标。

```cpp
int min3(int a, int b, int c) {
    int m = a < b ? a : b;
    return m < c ? m : c;
}

int max3(int a, int b, int c) {
    int m = a > b ? a : b;
    return m > c ? m : c;
}

int MinDistance(const int S1[], int n1, const int S2[], int n2, const int S3[], int n3) {
    int i = 0, j = 0, k = 0;
    int ans = INT_MAX;

    while (i < n1 && j < n2 && k < n3) {
        int a = S1[i], b = S2[j], c = S3[k];
        int mn = min3(a, b, c);
        int mx = max3(a, b, c);
        int d = 2 * (mx - mn);

        if (d < ans) {
            ans = d;
        }
        if (ans == 0) {
            break;
        }

        if (mn == a) {
            i++;
        } else if (mn == b) {
            j++;
        } else {
            k++;
        }
    }
    return ans;
}
```

复杂度：时间复杂度 `O(n1+n2+n3)`，空间复杂度 `O(1)`。

## 15 计算 res[i] = max(A[i] * A[j]), i <= j <= n-1

解析：固定 `A[i]` 后，若 `A[i] >= 0`，最大乘积来自后缀最大值；若 `A[i] < 0`，最大乘积来自后缀最小值。逆序扫描时维护当前后缀最大值和最小值。

```cpp
void calMulMax(const int A[], int res[], int n) {
    int suffixMax = A[n - 1];
    int suffixMin = A[n - 1];

    for (int i = n - 1; i >= 0; i--) {
        if (A[i] > suffixMax) suffixMax = A[i];
        if (A[i] < suffixMin) suffixMin = A[i];

        if (A[i] >= 0) {
            res[i] = A[i] * suffixMax;
        } else {
            res[i] = A[i] * suffixMin;
        }
    }
}
```

复杂度：时间复杂度 `O(n)`，空间复杂度 `O(1)`，输出数组 `res` 不计入额外空间。
