# 跨层高频对比速查

| 主题 | 关键区分 |
|---|---|
| 冲突域 vs 广播域 | 集线器：两者都不隔离；交换机：**只隔离冲突域**（广播仍泛洪）；路由器：**两者都隔离** |
| 流量控制 vs 拥塞控制 | 流控 = 点对点，防接收方溢出；拥控 = 全局，防网络过载 |
| 超时重传 vs 快重传 | 超时 → cwnd = 1；3 冗余 ACK → cwnd 减半 |
| CIDR vs VLSM | CIDR 聚合（减路由条目）；VLSM 细分（省地址） |
| 数据报 vs 虚电路 | 独立选路不保序 vs 固定路径保序 |
| CSMA/CD vs CSMA/CA | 有线半双工边听边发 vs 无线不检测靠 ACK |
| PPP vs HDLC | 面向字节无确认 vs 面向比特有确认可靠 |
| RIP vs OSPF | 距离向量/UDP/跳数 15 vs 链路状态/裸 IP/Dijkstra |
| IP 地址 vs MAC 地址 | 跨路由器：IP 不变，MAC 逐跳改变 |
| 各层设备 | 物理层：中继器、集线器；链路层：网桥、交换机；网络层：路由器 |
