# 二 物理层

## 1 两大定理（★必背）

**奈奎斯特定理**（理想低通、无噪声，带宽 W Hz，V 种码元）：

- 最高**码元**传输速率 = `2W` Baud
- 最高**数据**传输速率 = `2W · log₂V` bps

**香农定理**（有噪声信道，信噪比 S/N）：

- 极限数据率 `C = W · log₂(1 + S/N)` bps
- 信噪比常以 dB 给出：`dB = 10 · log₁₀(S/N)`

> **注意**：奈奎斯特管码元数，香农管信噪比。二者同时给出时取**较小值**。
>
> **示例**：频率范围 3.5 ~ 3.9 MHz，则信道带宽 = 0.4 MHz

## 2 基本概念三组

**三大基本概念**：

- 数据（信息实体）→ 信号（数据的电气/电磁表现）→ 码元（数字信号计量单位）
- 信源 → 信道 → 信宿
- 速率（码元速率 Baud／信息速率 bps）· 波特（每秒码元数）· 带宽（Hz）

**传输方式**：

- **基带**：数字信号直接传，近距离
- **频带**：调制成模拟信号，远距离
- **宽带**：频带 + 信道分解（如 FDM）

## 3 编码与调制

### 3.1 数字数据 → 数字信号

| 编码 | 要点 |
| --- | --- |
| 不归零编码 NRZ | 高/零两种电平直接表示 1/0，全码元保持不变。**无自同步，有直流分量** |
| 归零编码 RZ | 每码元中途回到零电平，**归零沿可提取同步信息**，但带宽利用率低 |
| **反向非归零 NRZI** | **不看电平高低，看电平是否跳变**：一种值使电平翻转，另一种值保持不变（具体约定见图注）。解决了长串同值时的同步问题 |
| **曼彻斯特** | 一码元分两半，**每个码元中点必跳变** → 自带时钟。**以太网采用**，编码效率仅 50% |
| **差分曼彻斯特** | 中点仍跳变（作时钟），**靠码元起始处是否跳变区分 0/1：0 跳变，1 不跳变**。抗干扰更强 |
| 4B/5B | 4 位转 5 位，余下 16 种作控制码或保留。用于 100Base-FX |

![常用基带传输编码波形](图片_高清/基带编码波形.PNG)

> **★ 读波形口诀**
>
> - **曼彻斯特**：看**中点**——每码元中点必跳变，跳变方向表示数据
> - **差分曼彻斯特**：看**起始点**——起始处跳变 = 0，不跳 = 1；中点跳变只负责同步
> - **反向非归零 NRZI**：也看**起始处是否跳变**，但整个码元内电平不再中途变化
>
> **自同步能力**：曼彻斯特 = 差分曼彻斯特 > 归零码 > 非归零码

### 3.2 数字数据 → 模拟信号（键控法）

正弦载波 `A·sin(2πft + φ)` 有三个可调参数：**振幅 A、频率 f、相位 φ**。改哪个，就是哪种键控。

| 方式 | 变什么 | 载波频率数 | 抗干扰 | 带宽 | bit/码元 |
| --- | --- | --- | --- | --- | --- |
| **ASK** 幅移键控 | 振幅 | 1 | **最差** | 窄 | 1 |
| **FSK** 频移键控 | 频率 | **2** | 强 | **最宽** | 1 |
| **PSK** 相移键控 | 相位 | 1 | 较强 | 窄 | 1 |
| **DPSK** 差分相移键控 | 相位**差** | 1 | 较强 | 窄 | 1 |

**各自的特别之处（★考点）**：

- **ASK** —— 又叫 **OOK 通断键控**：有载波 = 1，无载波 = 0。电路最简单、成本最低；但噪声直接叠加在幅度上，**抗干扰最差**
- **FSK** —— **四者中唯一需要两个载波频率 f₁ / f₂** 的，分别代表 1 和 0。抗干扰强、应用最广；代价是两个频带都要占，**带宽最宽**
- **PSK** —— 2PSK 用**绝对相位**（0 表示 1，π 表示 0）。**缺陷是倒 π 现象／相位模糊**：接收端要靠本地相干载波做相位参考，参考相位一旦反相，所有判决集体出错
- **DPSK** —— 不看绝对相位，**只看相邻码元的相位有没有变**（变 π = 1，不变 = 0），因此**不需要绝对相位参考，专门用来解决 PSK 的倒 π 问题**。代价：误码**成对出现**，前一码元判错会带累后一个

> **★ 三句话记住区别**
>
> - ASK 变**幅**、FSK 变**频**、PSK 变**相**、DPSK 变**相位差**
> - **只有 FSK 要两个载波频率**，其余三种都只用一个载波
> - **DPSK 之于 PSK，等价于差分曼彻斯特之于曼彻斯特**：都是把"绝对电平/绝对相位"换成"有无变化"，从而不依赖绝对基准

**进制与速率**：

- 2ASK / 2FSK / 2PSK / 2DPSK 均为 **1 bit/码元**
- 多进制 M 元调制每码元载 `log₂M` bit，故 `数据率 = 波特率 × log₂M`
- QPSK（4 相位）= 2 bit/码元　·　8PSK = 3 bit/码元

### 3.3 QAM 正交幅度调制

**原理**：

- **QAM = 调幅 + 调相联合编码**：把幅度状态和相位状态放在同一个码元上
- 若有 m 种幅值、n 种相位 → 共 `m × n` 种信号状态，**每码元承载 `log₂(m × n)` bit**
- 数据率 = `波特率 × log₂(m × n)`

![正交幅度调制 QAM：AM / FM / PM 与组合思想](图片_高清/QAM调制.PNG)

> **★ 看图抓要点**：AM 看**有无幅度**、FM 看**频率 f1/f2 切换**、PM 看**相位 0/π 翻转**。QAM = 把 **AM 的幅度状态**和 **PM 的相位状态**叠在同一码元上 → `m × n` 种状态。

### 3.4 模拟数据 → 数字信号（PCM）

**过程**：抽样 → 量化 → 编码

- 抽样频率 ≥ **2 × 模拟数据带宽**（奈氏抽样定理）

## 4 三种交换方式（★对比）

### 4.1 电路交换 vs 报文交换 vs 分组交换

| | 电路交换 | 报文交换 | 分组交换 |
| --- | --- | --- | --- |
| 建立连接 | 需要，独占物理路径 | 不需要 | 数据报不需要／虚电路需要 |
| 建立时间 | **最长** | 无 | 无/短 |
| 传输时延 | **最小** | 大 | 较小 |
| 缓存要求 | 无 | **大**（整报文） | 小 |
| 适用 | 实时话音 | 早期电报网 | **计算机突发式通信** |

### 4.2 数据报 vs 虚电路

| | 数据报 | 虚电路 |
| --- | --- | --- |
| 连接 | 无 | 建立虚电路，选未用过的**虚电路号** |
| 分组头 | **完整目的地址** | **虚电路号**，无目的地址 |
| 路由 | 每个分组独立选路 | 同一虚电路走同一路径 |
| 有序到达 | **不保证** | **保证** |
| 结点故障 | 可绕行 | **全部中断** |
| 差错/流量控制 | 主机负责 | 网络或主机 |

## 5 传输介质与设备

### 5.1 物理层接口特性

物理层接口四特性：**机械（形状、数目、排列）、电气、功能（意义）、规程（顺序）**

### 5.2 传输介质分类

传输介质分两类：

- **导向介质**：双绞线、同轴电缆、光纤
- **非导向介质**：无线电波、微波、红外线、激光

> **注意**：介质本身不算物理层设备，视为**第 0 层**

### 5.3 各种传输介质对比（★）

| 介质 | 关键区分 |
| --- | --- |
| 双绞线 | **STP** 有屏蔽层抗干扰强／**UTP** 无屏蔽便宜，局域网主流。以太网单段限 **100 m** |
| 同轴电缆 | **50 Ω** 传基带数字（早期以太网）／**75 Ω** 传宽带模拟（**有线电视**） |
| 光纤 | **多模** 用 LED，多角度反射有模式色散 → **近距离**；**单模** 用激光，直线前进 → **远距离**。优点：带宽大、**抗电磁干扰** |
| 无线 | **微波沿直线传播**，需接力站或卫星；**卫星单跳时延约 250~270 ms**（最常考的缺点） |

### 5.4 物理层设备

**核心特征**：只搬运比特，不认识帧和 MAC 地址 → **冲突域、广播域都不隔离**

**术语定义**：

- **冲突域**：同一时刻只允许一个站点发送的范围（争用同一介质，受 CSMA/CD 约束）
- **广播域**：一个广播帧能够到达的所有站点范围

#### ★ 三层设备对隔离能力的对比（贯穿全书的高频考点）

| 设备 | 层次 | 隔离冲突域 | 隔离广播域 |
| --- | --- | --- | --- |
| 中继器 / 集线器 | 物理层 | ✗ | ✗ |
| 网桥 / 交换机 | 数据链路层 | **✓** | ✗（需划 **VLAN** 才能分割） |
| 路由器 | 网络层 | **✓** | **✓** |

#### 物理层设备详解

| 设备 | 处理信号 | 动作 |
| --- | --- | --- |
| **中继器** | 基带**数字** | **再生**（重新判决出干净 0/1，丢掉噪声） |
| **放大器** | 宽带**模拟** | **放大**（信号连噪声一起放大） |
| **集线器 Hub** | 基带**数字** | 多端口中继器 |

**关键特性**：

- **集线器**：物理上是星型网络，逻辑上是总线，**半双工**，N 个端口**共享一份带宽**
- 互连网段必须**协议、速率相同**；中继器**不做协议转换**，扩的是**距离**不是带宽
- **★ 5-4-3 规则**（10BASE5）：最多 **5** 段介质、**4** 个中继器，只有 **3** 段可挂机器
